# 会议助手 Pro

基于浏览器的会议录制 PWA，支持后台录制、悬浮小窗和多种视频格式。

**在线使用**: https://unplage.github.io/meeting/

## 功能特性

- **视频录制** — 支持 1080p / 720p / 480p / 360p 分辨率选择
- **多格式输出** — WebM (VP9/VP8) 和 MP4 (H.264) 录制，MP4 需浏览器支持
- **MP4 转换** — WebM 录像可通过 ffmpeg.wasm 在浏览器内转换为 MP4（首次加载约 25MB）
- **后台录制** — 切换标签页后自动弹出悬浮小窗，保持录制不中断
- **系统画中画** — 支持浏览器原生画中画（PiP）
- **暂停/继续** — 录制过程中可随时暂停
- **本地存储** — 所有录像保存在浏览器 IndexedDB 中，无需服务器
- **PWA 离线** — 支持安装到桌面，离线可用

## 使用说明

1. 打开页面后选择分辨率、录制格式和摄像头/麦克风
2. 点击「开始录像」，首次会请求摄像头和麦克风权限
3. 录制时切换标签页会自动显示悬浮小窗
4. 点击「停止」后录像自动保存到本地
5. 在录像列表中可以下载、播放、转换格式或删除

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `空格` | 暂停/继续 |
| `Esc` | 关闭小窗 |
| `Ctrl+S` | 停止录制 |
| `Tab` | 隐藏/显示界面 |

## 本地运行

本项目是纯静态站点，无需构建工具。启动本地服务器即可：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

> 注意：摄像头/麦克风 API 需要 HTTPS 或 localhost 安全上下文。

## 技术栈

- 纯 HTML + CSS + JavaScript，无框架依赖
- Service Worker 实现离线缓存
- IndexedDB 存储录像文件
- MediaRecorder API 进行音视频录制
- [ffmpeg.wasm](https://github.com/ffmpegwasm/ffmpeg.wasm) 实现浏览器内格式转换

## 部署

推送到 `main` 分支后通过 GitHub Pages 自动部署，站点路径为 `/meeting/`。
